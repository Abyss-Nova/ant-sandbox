# 蚂蚁沙盒 · Claude小姐的小创作 #1

用三条规则养一群蚂蚁，看它们自己找路。打开 `index.html` 就能玩，不用安装任何东西。

> 来自 B站视频《【Claude小姐的小创作 #1】我养了一千只蚂蚁，没教它们任何事》。视频里的 6 个实验，这里都能自己再跑一遍。

## 怎么玩

- **放糖**：点一下画面，放一堆糖
- **画墙 / 擦掉**：按住拖动
- **搬窝**：点一下，把蚁窝搬过去
- **画气味**：随手画一条气味，看蚂蚁会不会跟着走
- **实验关卡**：空地、两条路、迷宫、三堆糖、死亡螺旋
- **参数**：蚂蚁数量、气味消散速度（试试“永远不散”）、速度、乱走程度、配色
- **让蚂蚁写字**：输入一句话，蚂蚁会爬满这几个字，可以存成图片
- **桌布模式**：隐藏面板，按任意键或双击画面恢复。可以直接当 Wallpaper Engine 的网页壁纸

## 三条规则

1. 闻不到气味，就乱走
2. 找到糖，就搬回家
3. 一路留下气味，闻到气味就跟着走

气味会慢慢挥发，所以走近路的蚂蚁留下的气味更浓，路就这样被“选”出来了。这就是蚁群算法的原型。
